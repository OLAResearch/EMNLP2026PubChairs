# Instructions for Chairs

We, as EMNLP 2026 publication chairs, received this instruction from ACL 2026 publication chairs. Publication chairs of ACL 2026 rely on GitHub to manage the proceedings. However, this year EMNLP, workshop chairs already use a shared Google Drive folder. We follow this and use Google Drive. Each chair and workshop organizer upload the <ACRONYM>_data.tgz package of compiled proceedings to the shared Google Drive folder. 

The publication chairs directly manage the main long, main short, and findings volumes. We suggest adding contact details for at least one program chair to the repository for these volumes.

The workshop chairs and the chairs of other tracks (students, demos, …) must collect the contact information and compile the following Google Sheet EMNLP 2026 Publication Management. Each contact person must check the title of each volume. You can refer to the EMNLP 2025 proceedings for how to name the volume. Workshop chairs can share the link with all the workshop organisers to collect all the information. 
We need to collect all this information by a hard deadline. This information is crucial for requesting the ISBN and starting the publication process.

We need some information from each committee during the publication process. In the following sections, we list the kind of information we expect for each committee.


## Workshop chairs
- Contact information of one person (name, email) for each workshop. This person will be responsible for following the publication process of the workshop volume. 
- Check the volume title of each workshop. 
- We will send information on preparing the volume to each workshop contact person.

## Demonstration Chairs and Industry chairs
- Contact information of one demonstration chair (name, email). This chair will follow the publication process for the demos volume. 
- We will send information on preparing the volume to the contact person.

## Student Research Workshop Chairs
- Contact information of one student workshop chair (name, email). This chair will follow the publication process for the Student Research Workshop volume. 
- We will send information on preparing the volume to the contact person.

## Sponsorship Chairs
- Send us the sponsors’ logos in one of these formats (PNG, PDF, EPS).

## Tutorial Chairs
- Contact information of one tutorial chair (name, email). This chair will follow the publication process for the Tutorial volume. 
- A PDF file for each tutorial with the tutorial abstract and the author's bio. 
- YAML files as reported in “Additional Information for Workshop”.

## General Chair and Program Chairs
- Contact information of one program chair (name, email). This chair will follow the publication process for the long/short/findings volume.
- Message from the General Chair in a Tex file.
- Message from the Program Chairs in a Tex file.
- For each keynote: abstract with the bio and photo in a Tex file. 
- Final Program.
- To know which kind of information we need, you can check the EMNLP 2024 proceedings.

## Software

We use ACLPUB2: https://github.com/rycolab/aclpub2 

## Additional Information for Workshop, Student Research Workshop, Demo, and Tutorial Chairs

Each contact person for each volume should provide:
- A schedule: Manually defined in program.yml
- A list of papers: Automatically generated by openreview and stored in papers.yml
- A description of the workshop: Manually defined in description.yml
- A list of organisers: Manually defined in organizing_committee.yml
- A list of prefaces: Manually defined in prefaces.yml

We suggest following this guideline https://zeerak.org/workshops or the instructions of the ACLPUB2 tool.
This additional information can be sent to the contact person of each workshop.
